Visual Guide

Anima 2B Explorer shows how the Anima 2B model draws 40,000 artists from the Danbooru dataset.

We generated each image with the prompt 1girl, artist_name. We locked the CFG and steps to standard values. This shows the base interpretation of the style.

Features

  • 40,000 Styles: Browse the artists in a responsive grid. Change the grid size with the slider.
  • Sort: Order the artists by Name, Works (dataset popularity), Uniqueness, Date, or Random.
  • Similar Artists: Find artists with a related style.
  • Favorites: Save artists to your personal list. Export the list as a JSON file or a TXT file for ComfyUI wildcards.

Navigation and Hotkeys

  • Arrow Keys: Move the focus across the grid.
  • Mouse Click: Open the QuickLook preview.
  • Double-click / Double-tap: Add the artist to your favorites.
  • Middle-click: Open the QuickLook preview.
  • Scroll Wheel: Switch photos in the QuickLook preview.
  • F: Add the artist to your favorites.
  • C: Copy the artist name to the clipboard.
  • Enter: Open the Similar Artists panel.
  • Escape: Close the active window.
